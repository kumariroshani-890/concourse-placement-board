# Concourse — Campus Placement Board

A premium home page concept for campus placements, designed as a
departures board to make deadlines and placement drives easier to track.

## Live Demo

https://concourse-career.netlify.app/

## Assignment

**Acdyon Technologies — Frontend Challenge**

**Track:** Part 2 — The Premium Home Page

## Features

- Responsive design for mobile and desktop
- Interactive placement board
- Add placement drives
- Drive detail view
- Filter and sort drives
- Live countdown
- LocalStorage persistence
- Dark / Daylight mode
- Responsive mobile layout
- Konami-code easter egg

## Tech Stack

- HTML
- CSS
- JavaScript
- Browser LocalStorage
